A1 SPARC V2 design reference

The 2020 SPARC V2 design specifies a compact, high-field deuterium–tritium tokamak. The values below describe its nominal design.

Major radius R0
1.85 m
Minor radius a
0.57 m
On-axis toroidal field B0
12.2 T
Plasma current Ip
8.7 MA

For the nominal full-field H-mode case with H98,y2 = 1, the design study projects about 140 MW of total fusion power and a dimensionless plasma fusion gain Q of about 11. These are model predictions for the reference discharge.

Design and projections · A. J. Creely et al. (2020), Overview of the SPARC tokamak. DOI 10.1017/S0022377820001257

Core-plasma modeling · P. Rodriguez-Fernandez et al. (2020), Predictions of core plasma performance for the SPARC tokamak. DOI 10.1017/S0022377820001075

A2 cfspopcon Primary Reference Discharge

Commonwealth Fusion Systems publishes cfspopcon for evaluating plasma operating contours. Its Primary Reference Discharge example specifies a linear grid of 40 volume-averaged electron densities (input units of 1019 m−3) and 30 volume-averaged electron temperatures (keV). Fixed input values include a 1.85 m major radius, a 12.2 T on-axis toroidal field and an 8.7 MA plasma current. The upstream documentation describes changes from the 2020 physics basis.

Software version 9.0.1 · fixed revision 0ebfb43c614c71b0c6946209b826cfc19da6a0e8 · MIT software license.

A3 SPARCPublic reference files

Commonwealth Fusion Systems publishes the 2022-10-13 Primary Reference Discharge as design reference data. The files below are unchanged original bytes. The equilibrium and kinetic profile files describe design models.

  • FreeGS GEQDSK

    Double-null reference equilibrium with a simplified first wall. 301,719 bytes.

    Download FreeGS GEQDSKUpstream file

  • TRANSP

    One-dimensional reference kinetic profiles. 11,593 bytes.

    Download TRANSPUpstream file

  • CGYRO

    One-dimensional kinetic profiles from a separate modeling workflow. 22,993 bytes.

    Download CGYROUpstream file

The kinetic profile files report electron and ion temperatures in keV and electron density in 1019 m−3. No fields or units have been transformed.
